# GAP-NN-LAD: Global Average Pooling Nearest Neighbor Logical Anomaly Detection

Steps to run:
1. ensure that you have MVTecLOCO AD dataset available
2. ensure that dependencies from `requirements.txt` are installed
3. run `python run_experiments.py --root_dir <path to dataset>`
4. outputted results will be in `runs/final` or wherever was passed to `--out_root`
